Embeddings

An embedding is a fixed-length vector computed from a snippet's audio. YAPAT computes embeddings once per snippet set and reuses them for similarity search, active learning, and projection views.

Why embeddings

Comparing raw audio directly is costly. With one vector per snippet, YAPAT can find the snippets closest to a reference using pgvector's cosine distance, and it can give a classifier compact features to learn from.

Embedding models

GET /api/embedding-models lists the registered models. Each record holds the window size, step size, and overlap the model works with, so the same model has to be used when snippets are compared. The initial database migration registers one model, BirdNET version 2.4, described as using 3-second windows at 48 kHz, with a window of 3.0 seconds, a step of 3.0 seconds, and no overlap. Its vectors have 1024 dimensions.

Snippet sets

Running an embedding job produces a snippet set: a collection of snippets cut with a specific window and step, together with the embeddings from one model. A dataset can have several snippet sets. It is ready for feeds only when it has a snippet set with status ready.

Job lifecycle

Embedding generation runs asynchronously. The client requests a job and a Celery worker processes the recordings in chunks: 

POST /api/datasets/{dataset_id}/embeddings
GET  /api/datasets/{dataset_id}/embeddings
GET  /api/embeddings/{job_id}

A repeated request for the same configuration returns a conflict (HTTP 409) instead of starting a second job. A snippet set that already has annotations can be deleted only if the request explicitly sets acknowledge_annotation_loss to true.

What embeddings are used for

  • Similarity feeds — find snippets near a reference snippet or an uploaded sound.
  • Active learning — train and score a classifier on embedding vectors; a cold-start run needs an embedding model.
  • Projections — the Annotation Hub shows a 2D projection of the snippets (PCA, UMAP, t-SNE, or Isomap). The API can also compute 3D projections; the current interface requests 2D only.
Operational note. Embedding jobs run on the Celery embeddings queue. See Deployment for worker settings.
