Grounding

Grounding means linking a concept you describe in your own words to an entry in a trusted source. For example, you describe a bird species, the assistant suggests matching entries from the Global Biodiversity Information Facility (GBIF), and the one you choose keeps its GBIF identifier.

How it works

YAPAT tries trusted sources first and only creates a local concept when none of them has a match. You always make the final choice.

What is kept

Each concept keeps its identifier, the details its source returned (such as rank, family, and kingdom), where it came from, and when it was added. The chat history is saved with the conversation, so you can see how the label space was built.

For developers.
  • Lookups run in the separate oe_yapat service, a Model Context Protocol (MCP) tool server. Its tools look up GBIF, the Environment Ontology (ENVO) through the Ontology Lookup Service (OLS) of the European Bioinformatics Institute (EBI), and Wikipedia, and can write local Web Ontology Language (OWL) modules.
  • The backend forwards each chat message to POST {OE_YAPAT_SERVICE_URL}/api/generate-taxonomy; the chat API is under /api/taxonomy/chat.
  • GET /api/taxonomy/match and /api/taxonomy/envo/suggest call GBIF and EBI OLS directly, so the backend needs outbound internet access. The Hub's species search calls GBIF from the browser.
  • There is no separate grounding-status field; the source is visible in each entry's identifier and metadata.
