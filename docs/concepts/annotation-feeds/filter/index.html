Filters and Model Scores

Filters let you focus on part of a dataset, for example unlabelled snippets from one site at dawn. They narrow both the feed and the projection, and the feed can be sorted by the same values.

Filters

The sidebar on the left of the Annotation Hub contains the following filters:

FilterShows
StatusAll, unlabelled, or labelled snippets; labelled snippets can be narrowed to chosen species.
LocationSnippets from one or more recording sites.
Date and timeA date range, months of the year, and a time of day.
Model scoresSnippets within a range of each score, set with sliders over a histogram.

Each histogram shows how the snippets are distributed over that value.

Location, date, and time come from each recording's metadata: read from file names such as SITE_YYYYMMDD_HHMMSS, or uploaded as a comma-separated values (CSV) file on the Datasets page.

The Sample properties and Model derived scores sections can be collapsed, and the icon next to Filters hides the sidebar.

What the model scores mean

ScoreHigh means
UncertaintyThe model is unsure about this snippet. The feed is ranked by it.
DiversityThe snippet is unlike the snippets already labelled.
DensityThe snippet sits among many similar snippets, so it represents a common sound.
CompositeA weighted mix, by default half uncertainty and a quarter each diversity and density.
ConfidenceThe model is confident it hears something; with species selected, confident it hears one of them.

The scores help you choose what to label; the model's predicted labels themselves stay hidden.

Sorting

The Sort bar above the feed sorts it by one or more of: confidence, composite, uncertainty, diversity, density, date, and time.

For developers. Uncertainty, diversity, density, and composite come with each prediction from the Active Learning API; confidence is computed in the browser from the predicted probabilities. The scoring code is in the backend's active_learning/samplers.py.
