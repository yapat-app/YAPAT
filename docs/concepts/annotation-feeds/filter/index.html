Filter

The filter feed restricts snippets by explicit criteria — annotation status, recording location, and species — so you can target a specific slice of the dataset.

Available filters

Filter Values
annotation_status any, annotated, or unannotated.
location One or more recording locations, comma-separated.
species One or more species, comma-separated.

Requesting a filter feed

GET /api/feed/?method=filter&dataset_id={dataset_id}
    &annotation_status=unannotated
    &location=site-a,site-b
    &limit=50

When to use it

  • Reviewing only what is still unannotated.
  • Auditing everything already labelled with a species.
  • Working through one recording site at a time.

A recording's location is its location metadata value or, when that is missing, the part of its file name before the first underscore. Locations can be listed for a dataset through the recording-locations endpoint. Filter feeds are snapshotted like the other methods, so a configuration can be reopened from Feed History.
