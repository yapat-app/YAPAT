Similarity

The user-study version has no similarity annotation mode. The Annotation Hub's "Find similar" control is switched off in every study phase, and the Hub never shows a feed of similar snippets.

What the user-study version does instead

Every feed in the Annotation Hub comes from active learning. Embeddings are still central to it: the active-learning model is trained on them, and the projection view is computed from them.

The backend code still contains older similarity-search endpoints from an earlier feed design. They are not part of the user-study workflow and are not described in these pages.
