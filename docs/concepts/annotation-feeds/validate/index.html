Validate

Validate mode is a review pass: it ranks unannotated snippets by the model's confidence so an expert can confirm or correct them. It is available from the Annotation Hub with ?mode=validate.

Configuration

  • Label scope — restrict the pass to one or more focus species.
  • Minimum confidence — ignore suggestions below a threshold.
  • Top-K — cap the number of unannotated snippets to review.

The result is a confidence-ranked list of unannotated snippets. The annotator works through it, accepting a suggestion to turn it into a label or rejecting it when the model is wrong.

Why validate

A validation pass lets an annotator check the model's most confident suggestions. Each accepted suggestion becomes a stored label and is recorded as feedback, so the pass also checks the model's output and supplies labels for later retraining.

Difference from active learning. Active learning orders snippets with a chosen strategy, such as uncertainty, diversity, density, or a composite of them. Validate orders unannotated snippets by the model's confidence instead.
