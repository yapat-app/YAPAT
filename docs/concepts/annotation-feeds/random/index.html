Random

The user-study version has no random annotation mode. Random sampling appears in one place: bootstrap mode, which starts a dataset's first active-learning session when no model checkpoint exists.

When it is used

When a dataset has no checkpoint, the Generate Feed dialog in the Annotation Hub asks whether ground-truth metadata is available. If that option is left off, the session starts in bootstrap mode, and the backend returns randomly chosen snippets from the dataset's default snippet set instead of model-ranked ones.

Behaviour

The annotator labels these snippets as usual. Because no checkpoint exists yet, the labels are stored as feedback without a model. Once the number of labelled snippets reaches the retrain threshold, a first model is trained from those labels, and from then on the feed is ranked by that model.

After bootstrap. Once a model exists, snippets are ranked by it. See Active Learning.
