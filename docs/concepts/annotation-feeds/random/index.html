Random

The random feed draws a random sample of snippets from a dataset. It applies no model and does not favour any snippets.

When to use it

  • A first look at an unfamiliar dataset.
  • Establishing a baseline before model-assisted sampling.
  • Covering the soundscape broadly, including common and background sounds.

Requesting a random feed

GET /api/feed/?method=random&dataset_id={dataset_id}&limit=50

The client may also scope the sample to a specific snippet set or recording, and control paging with skip.

Behaviour

The endpoint resolves the dataset's default snippet set when none is given, and rejects datasets whose snippet set is not ready. Each random feed is saved as a snapshot for the requesting user, and up to five snapshots per method are retained.

Contrast. A random feed ignores model output. To bias sampling toward likely or informative snippets, see Active Learning or Similarity.
