Project

YAPAT is an annotation tool for passive acoustic monitoring audio. It uses machine-learning models to decide which samples an expert labels next, with the aim of reducing the labelling effort needed to collect training data.

Repository structure

The main repository links the components as Git submodules:

Directory Repository Contents
frontend/ yapat-frontend The annotation interface, built with React, TypeScript, and Vite.
backend/ yapat-backend The FastAPI application, Celery workers, and the machine-learning code for embeddings and active learning.
oe_yapat/ oe_yapat An MCP tool server for looking up concepts in GBIF, ENVO (through OLS), and Wikipedia, plus an ontology tool for locally defined concepts, and a command-line client.
WSSED/ WSSED-YAPAT A FastAPI server for training and running weakly supervised sound event detection models on GPU hardware.
docs/ — The static site you are reading.

Hosted instance

The repository's benchmark scripts use https://yapat.ni.dfki.de as the address of the project's hosted instance. The backend serves its REST API under the /api prefix; see the REST API reference.

Background

The two papers summarised under Research Context come from the German Research Center for Artificial Intelligence (DFKI) in Oldenburg and the University of Oldenburg, and were written within the DFKI project area Computational Sustainability & Technology.
