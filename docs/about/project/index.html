Project

YAPAT is an AI-powered annotation tool for passive acoustic monitoring audio, developed at the German Research Center for Artificial Intelligence (DFKI). It uses active learning to reduce the time experts spend labelling.

Repositories

DirectoryRepositoryContents
frontend/yapat-frontendThe web interface (React, TypeScript, Vite).
backend/yapat-backendThe application programming interface (API), background workers, and machine-learning code (FastAPI, Celery).
oe_yapat/oe_yapatThe ontology tool server behind the label-space chat.
WSSED/WSSED-YAPATThe training server for Weakly Supervised Sound Event Detection (WSSED), which trains sound event detection models. See WSSED.
docs/—This documentation site.

The main repository, yapat-app/YAPAT, links them as Git submodules.

Hosted instance

A hosted instance is linked from this documentation: yapat.ni.dfki.de. Access to it is managed by its operators.
