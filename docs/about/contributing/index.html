Contributing

YAPAT is open source. Bug reports, ideas, and code are welcome.

Report a bug or suggest a feature

Open an issue in the YAPAT issue tracker. For a bug, include the steps to reproduce it, what you expected, what happened, and a screenshot or the relevant log lines (see Troubleshooting for where to find logs).

Contribute code

YAPAT is split across repositories; the main repository links them as Git submodules. Make a change in the repository it belongs to:

ChangeRepository
The web interfaceyapat-frontend
The application programming interface (API), workers, or machine learningyapat-backend
The label-space assistant's lookupsoe_yapat
This documentationYAPAT, in docs/
  1. Set up a development environment: Development Setup.
  2. Create a branch, make the change, and run the tests and the linter.
  3. Open a pull request that explains what changed and why.

Architecture and Extending YAPAT show where things live in the code.

Editing this documentation

The documentation is a static site in docs/. Each page is an index.html in its own folder, and the navigation is defined in docs/js/docs-config.js. Preview it locally with: 

python3 -m http.server -d docs
