Environment Setup

The backend reads configuration from environment variables, with defaults in app/config.py and a documented example in backend/.env.example. The frontend uses Vite variables.

Mode selection

VariableNotes
DEVICEcpu (default) or gpu; selects the PyTorch build used by the Docker image.
COMPOSE_FILESet to docker-compose.yml:docker-compose.gpu.yml to add GPU runtime.

Connection pools and task limits

The user-study backend has no environment variables for the database connection pool; its size is fixed in code (see Deployment). The task and worker settings are:

VariableDefaultPurpose
CELERY_TASK_TIME_LIMIT3600Hard time limit for general tasks.
CELERY_TASK_SOFT_TIME_LIMIT3300Soft time limit for general tasks.
SCAN_TASK_TIME_LIMIT90000Longer budget for dataset scans.
SCAN_TASK_SOFT_TIME_LIMIT86400Soft budget for dataset scans.
EMBEDDING_CHORD_CHUNK_SIZE25Recordings per embedding chunk task.
CELERY_WORKER_MAX_TASKS_PER_CHILD100Worker memory-recycling threshold.

Frontend variables

VariableRequiredPurpose
VITE_YAPAT_BACKEND_URLNoBackend API base URL; defaults to http://localhost:8000. The frontend container can also set it at start-up.
VITE_YAPAT_FRONTEND_URLNoPublic frontend URL used for invitation links.
VITE_STUDY_PHASENoDefault study phase of the Annotation Hub (P1 to P5); P1 when unset.
VITE_STUDY_PHASE_LOCKNoWhen true, the phase from the environment is used and the URL parameter and stored choice are ignored.
VITE_STUDY_PHASE_ALLOWEDNoComma-separated phases a locked session may switch between, in order; also the sequence of the guided study flow.
VITE_STUDY_FLOW_ENABLEDNoGuided study flow: an instructions dialog and a guided tour for each phase. On by default when the phase is locked.
VITE_STUDY_PHASE_DURATION_MINUTESNoMinutes per phase (default 5). The countdown that would use it is switched off in the user-study frontend, so phases do not advance automatically; the value only appears in logged study-flow events.
VITE_STUDY_LOGGING_ENABLEDNoSends a timestamped log of interactions to /api/study-events/batch; off by default.
VITE_STUDY_LOGGING_FLUSH_SECONDSNoHow often logged events are sent; default 10 seconds.
Defaults vs. deployment. Compose files override some defaults (for example JWT lifetime and broker addresses). Always diff the environment against backend/.env.example and frontend/.env.example when deploying a new stack.
