Troubleshooting

Find the symptom below. If your problem is not listed, see Reporting a problem.

Start here

cd backend
docker compose ps                 # which services are running
docker compose logs -f api        # follow one service's log

The services are api, celery-worker, celery-worker-pam-al, celery-beat, db, redis, and flower. Flower, at http://localhost:5555, shows every background task and its result.

Signing in

"Incorrect username or password"

Check the username and password. If you have no account yet, register on the sign-up page or ask an administrator for an invitation link.

Datasets and embeddings

The folder picker in Add Dataset is empty

YAPAT only sees folders on its data volume. Set HOST_DATA_ROOT in backend/.env to the folder that holds your audio and restart the backend. The picker is available to administrators only.

Generate Embeddings is greyed out

The folder scan is still running; the button's tooltip says so. Wait for it to finish. Only administrators see the button; other users are asked to contact an administrator.

"No READY default snippet set found for this dataset"

The Generate Feed dialog shows this when the dataset has no embeddings yet, or the job has not finished. Generate embeddings on the dataset card and wait for the job in Flower.

Annotation

Only phase 1 is available

The example frontend settings lock the Hub to phase 1. In frontend/.env, list the phases you want in VITE_STUDY_PHASE_ALLOWED (or remove it to allow all five), set VITE_STUDY_PHASE_LOCK=false, and restart the frontend. See Environment Setup.

The model does not seem to retrain

Retraining starts after 10 new labels. It runs on the celery-worker-pam-al service, so check that it is running and read its log.

A feed from the dataset card does not appear in the Hub

The Generate Feed button on the dataset card uses an older feed type that the Hub does not show. Use Generate Feed inside the Annotation Hub.

Species search or label lookups fail

The Hub's species search calls the Global Biodiversity Information Facility (GBIF) from the browser, and the backend calls GBIF and the Ontology Lookup Service (OLS) of the European Bioinformatics Institute (EBI) to resolve labels. Both need internet access.

A label is missing from the export

The export contains labels that resolve to a source identifier or a species name. See Import & Export.

Label spaces and teams

The label-space chat does not answer

The chat needs the ontology service. Check that it is running and that OE_YAPAT_SERVICE_URL points to it; from Docker, use http://host.docker.internal:8002 for a service on the same host. See Installation.

Team Management shows "Team not found."

A team owner who belongs to a team is taken to the team page, which cannot load. Ask an administrator to invite people or change the team from the team list. See Teams.

An invitation link does not work

Links expire after two days; ask for a new one. If links point to localhost, set VITE_YAPAT_FRONTEND_URL to the public address of the frontend.

The WSSED card is missing

The card for Weakly Supervised Sound Event Detection (WSSED), which trains sound event detection models, is shown to administrators and to users with access to a FOCAL_RECORDINGS dataset.

Setup

The frontend cannot reach the backend

The frontend calls VITE_YAPAT_BACKEND_URL, which defaults to http://localhost:8000. Set it if the backend runs elsewhere, and check that http://localhost:8000/health answers.

You are signed out unexpectedly

Sign-in tokens expire after ACCESS_TOKEN_EXPIRE_MINUTES: seven days in the Docker Compose stack, 30 minutes otherwise. Sign in again.

A port is already in use

The stack uses 5432 (PostgreSQL), 6380 (Redis), 8000 (API), 5555 (Flower), and 3000 (frontend). Stop the other program, or change the port mapping in docker-compose.yml. See Docker.

Reporting a problem

Open an issue in the issue tracker with the steps to reproduce, what you expected, and a screenshot or the relevant log lines.
