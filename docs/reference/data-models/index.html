Annotation

FieldTypeNotes
idintegerPrimary key.
snippet_idintegerAnnotated snippet.
user_idintegerAuthor.
usernamestring | nullAuthor's username, in responses.
taxon_idstringNamespaced concept ID such as gbif:…, custom:…, wiki:…, or local:….
resolved_name_snapshotstringName of the concept at the time of annotation.
extra_metadataJSON | nullFree-form metadata.
created_at, updated_atdatetimeCreation and last-update times.

When creating an annotation, the request supplies exactly one of taxon_id or species_name, plus an optional display_name; the backend stores the resolved taxon_id and name. A snippet can carry several labels, but the pair snippet_id and taxon_id is unique.

User feed

FieldTypeNotes
idintegerPrimary key.
user_idintegerUser who generated the feed.
methodstringrandom, similarity, or filter.
request_paramsJSONThe full request that produced the feed.
responseJSONThe list of snippets the feed returned.

The database retains the last five snapshots per user and method; older entries are dropped.

Sample scores

The backend attaches uncertainty, diversity, density, and composite_score to each projection point. The table below is the frontend's per-snippet view model, which also carries display fields; it is not a database entity.

FieldTypeNotes
uncertaintyfloatModel uncertainty for the snippet.
diversityfloatEmbedding-space dispersion.
densityfloatLocal neighbourhood density.
composite_scorefloatWeighted blend of the above.
year_cyclefloat | nullTemporal cycle feature.
day_cyclefloat | nullDiurnal cycle feature.
sound_typestring | nullBio, Anthro, or Geo.
birdnet_labelstring | nullBirdNET predicted label.
yamnet_labelstring | nullYAMNet predicted label.
actual_labelstring | nullUser-supplied ground truth.

Feature-projection view

POST and GET /api/visualisations/fpv return the projection data directly. The response holds points (snippet ID, predicted labels, and the four scores), projections_2d, and, when requested with run_3d, projections_3d. Each projection map is keyed by method (pca, umap, tsne, isomap). An optional method_availability object marks methods that will not be computed for a dataset of this size, with an available flag and a reason. Asynchronous generation with a queued task_id belongs to POST /api/visualisations/fpv-dataset, whose data is then read with GET on the same path. The Annotation Hub uses only the 2D projections.
