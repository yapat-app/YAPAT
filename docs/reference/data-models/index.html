Sample scores

Each prediction row and each projection point carries these scores for its snippet, next to the predicted labels:

FieldTypeNotes
uncertaintyfloat | nullModel uncertainty for the snippet.
diversityfloat | nullEmbedding-space dispersion.
densityfloat | nullLocal neighbourhood density.
composite_scorefloat | nullWeighted blend of the above.

Prediction rows also carry predicted_labels and predicted_probabilities. The Annotation Hub uses them for ranking and for the confidence score, and does not show the predicted labels to annotators.

Feature-projection view

The Annotation Hub starts projection generation for the whole dataset with POST /api/visualisations/fpv-dataset, which queues a task and returns its task_id, and reads the result with GET on the same path. The projection data holds points (snippet ID, predicted labels, and the four scores), projections_2d, and, when requested with run_3d, projections_3d. Each projection map is keyed by method (pca, umap, tsne, isomap). An optional method_availability object marks methods that will not be computed for a dataset of this size, with an available flag and a reason. The Hub uses the 2D principal component analysis (PCA), Uniform Manifold Approximation and Projection (UMAP), and t-distributed stochastic neighbor embedding (t-SNE) projections. The backend's /api/visualisations/fpv endpoints return the same kind of data for a model family; the web interface does not call them.
