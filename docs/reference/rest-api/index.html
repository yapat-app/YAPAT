REST API

Everything the web interface does goes through this API, so anything you can do in YAPAT you can also script. The backend is a FastAPI application; every route is under /api, except GET / and GET /health. A running backend also serves interactive docs at /docs.

Authentication

Protected routes expect an HTTP Authorization: Bearer <token> header. Tokens come from the login endpoint and are self-contained JSON Web Tokens (JWTs). Their lifetime is ACCESS_TOKEN_EXPIRE_MINUTES: 30 minutes by default in the backend settings, and seven days in the Docker Compose stack. Status conventions:

  • 401 — missing, expired, or invalid credentials.
  • 400 — the authenticated user is inactive.
  • 403 — the user lacks the required admin, team, or dataset permission.
