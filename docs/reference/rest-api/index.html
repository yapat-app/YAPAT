REST API

The YAPAT backend is a FastAPI application. Every route is mounted under the /api prefix; the only exceptions are GET / and GET /health.

Authentication

Protected routes expect an HTTP Authorization: Bearer <token> header. Tokens are obtained from the login endpoint and are self-contained JWTs; the default lifetime is seven days (ACCESS_TOKEN_EXPIRE_MINUTES). Status conventions are:

  • 401 — missing, expired, or invalid credentials.
  • 400 — the authenticated user is inactive.
  • 403 — the user lacks the required admin, team, or dataset permission.
