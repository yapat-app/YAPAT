Feed Methods

The GET /api/feed/ endpoint is the single entry point for classic feeds. The method parameter selects the behaviour and controls which additional parameters are accepted.

Common parameters

Parameter Applies to Notes
dataset_idAllTarget dataset.
snippet_set_idAllOptional; resolves the dataset default when omitted.
recording_idAllOptional; restrict to one recording.
limitAllMaximum snippets to return; up to 1000.
skipAllOffset for paging.

Random

GET /api/feed/?method=random&dataset_id=1&limit=50

Returns a randomly ordered sample from the snippet set. No additional filter parameters are required.

Similarity

Two inputs are possible.

From an existing snippet:

GET /api/feed/?method=similarity
    &dataset_id=1&query_snippet_id=42&embedding_model_id=1
    &crop_start_sec=0.5&crop_end_sec=2.5&limit=50

From an uploaded audio region:

POST /api/feed/similarity-search
multipart/form-data fields:
  audio_file        Audio clip (WAV/MP3/FLAC/OGG/M4A/AAC, ≤ 100 MB)
  start_time        Reference start (seconds)
  end_time          Reference end (seconds)
  dataset_id        Target dataset
  embedding_model_id  Model used for the dataset's snippet set
  limit             Result cap (≤ 100)
  skip              Offset

Snippets are ranked by cosine distance between embeddings, so embedding_model_id must match the model used for the target snippet set.

Filter

GET /api/feed/?method=filter&dataset_id=1
    &annotation_status=annotated
    &location=site-a,site-b
    &species=Turdus%20merula
    &limit=50
Parameter Values
annotation_statusany, annotated, or unannotated.
locationComma-separated location strings.
speciesComma-separated species.

Snapshots

Every successful random, similarity, or filter request is persisted as a snapshot for the requesting user. Up to five snapshots per method are retained; older ones are silently dropped. The snapshot stores the full request parameters and the resulting snippet list so that the same feed can be reopened from Feed History.

Active-learning feeds are driven by /api/pam-al/inference/get-or-create rather than the classic feed endpoint. See Active Learning.
