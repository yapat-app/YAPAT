Import & Export

Audio is registered by reference rather than uploaded, and annotations are exported as JSON or CSV.

Importing a dataset

YAPAT does not copy audio into the database. A dataset stores a source_uri that points at a directory on the mounted data volume. In the web interface, an administrator browses that volume and picks the folder when adding the dataset; the API offers GET /api/datasets/available-paths for this, restricted to administrators. 

POST /api/datasets/
{
  "name": "Forest 2026",
  "dataset_type": "PAM",
  "source_uri": "/data/forest-2026",
  "team_id": 1
}

The path must exist and be a directory. A dataset with the same team and source folder is rejected as a duplicate (HTTP 409), and non-administrators must supply a team_id. Creating a dataset schedules a background processing task that scans the folder, discovers audio files, and creates recording entries. A scan can be triggered again later, and progress is available from the task-status endpoint. The data volume is mounted read-only, so processing never modifies the original files.

Exporting annotations

Annotation export returns the user labels of a dataset together with recording and snippet metadata: 

GET /api/datasets/{dataset_id}/annotations/export?format=csv
Parameter Purpose
formatjson (default) or csv.
labelsComma-separated labels. Only annotations carrying one of them are exported. A label can be given as an active-learning label string, a taxon ID, or a resolved species name.
taxon_idA single label; an alias for labels. Supplying both is rejected.
include_co_occurringWhen true, a snippet that matches the label filter is exported with all of its annotations, including other labels. Ignored without a label filter.
user_idRestrict to one annotator.
created_after, created_beforeRestrict by creation time.

The columns are annotation_id, dataset_id, snippet_id, label, created_at, created_by, recording_file_name, snippet_start_time, snippet_end_time, and snippet_duration. Administrators also receive a source_table column. The export combines labels from the active-learning label store and the canonical annotation table, removes duplicates per snippet, label, and user, and includes user-source labels only, so ground-truth labels are left out.

To list the labels that actually occur in a dataset, for example to build a label filter, call GET /api/datasets/{dataset_id}/annotation-labels.

Traceability. Every exported row names the recording and gives the snippet's start time, end time, and duration, so a label can be traced back to the audio window it describes.
