Workflow Overview

YAPAT turns raw audio into annotated training data through a sequence of asynchronous stages. Each stage produces an object the next one consumes, and each can be re-run independently.

Stages

# Stage Produces
1 Register dataset A Dataset pointing at a folder on the data volume.
2 Scan / process Recording rows discovered from files, with metadata.
3 Embed A SnippetSet of snippets and their embedding vectors.
4 Define label space A label space promoted to active by a team owner (see Managing Versions).
5 Generate feed An ordered batch of snippets to annotate.
6 Annotate Annotation and feedback records.
7 Train / retrain An active-learning checkpoint that re-ranks the next feed.
8 Export JSON or CSV of the dataset's annotations.

Asynchronous execution

Steps 2, 3, and 7 run on Celery workers rather than in the request. The API returns immediately with a task or job identifier, and the client polls for status. Queues are separated so that heavy training does not block interactive work:

  • processing — dataset scanning and snippet creation.
  • embeddings — audio embedding generation.
  • exports — export and report generation.
  • pam_al — active-learning training and retraining.
  • default — general fallback tasks.

Iteration

Steps 5, 6, and 7 form a loop: annotate a batch, let the annotations accumulate, retrain, and generate a new batch ranked by the updated model. Random, similarity, and filter feeds do not depend on a trained model and can be used at any point.
