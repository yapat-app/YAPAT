Development Setup

Everything you need to change YAPAT's code and see the result: live reload for the backend and frontend, migrations, and tests. Start with Installation if YAPAT is not running yet.

Backend with live reload

Docker Compose automatically applies docker-compose.override.yml, so a plain docker compose up in backend/ already runs in development mode: your source folder is mounted into every container, and the API restarts when a Python file changes. Celery workers do not reload; restart them after changing a task: 

docker compose restart celery-worker celery-worker-pam-al

To run the stack without the development override, name the files explicitly: docker compose -f docker-compose.yml up. For a graphics processing unit (GPU), add -f docker-compose.gpu.yml.

Logs and background tasks

docker compose logs -f api                    # the API
docker compose logs -f celery-worker-pam-al   # active-learning training

Flower at http://localhost:5555 lists every background task with its arguments, result, and error. The interactive API docs at http://localhost:8000/docs let you call any endpoint.

Database migrations

Migrations run automatically when the api container starts. After changing a model in app/models/, create a migration and apply it: 

docker compose exec api alembic revision --autogenerate -m "describe the change"
docker compose exec api alembic upgrade head

Review the generated file in alembic/versions/ before committing it.

Tests

docker compose exec api pytest tests/unit
docker compose exec api pytest tests/integration

Frontend

CommandDoes
npm run devDevelopment server with hot reload at http://localhost:3000.
npm run lintRuns ESLint.
npm run buildType-checks and builds the production bundle into dist/.
npm run previewServes the production build locally.

Frontend settings are VITE_* variables in frontend/.env. Vite reads them at start-up, so restart npm run dev after changing one. See Environment Setup.
