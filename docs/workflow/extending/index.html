Extending YAPAT

The changes people make most often, and the files to make them in. Set up a development environment first; see Development Setup.

Tune active learning

The defaults live in the backend's active_learning/config.yaml. They are read when a process starts, so restart api and celery-worker-pam-al after editing.

SettingDefaultControls
RETRAIN_AFTER10New labels before an automatic retrain. A dataset's retrain_after_threshold column overrides it.
DEFAULT_EPOCHS, DEFAULT_LEARNING_RATE, DEFAULT_BATCH_SIZE20, 0.001, 512Classifier training.
DEFAULT_HIDDEN_DIM, DEFAULT_DROPOUT128, 0.5Size and regularisation of the classifier.
DEFAULT_INFERENCE_THRESHOLD0.3Probability above which a species counts as predicted.
DEFAULT_COMPOSITE_WU, _WD, _WR0.5, 0.25, 0.25Weights of uncertainty, diversity, and density in the composite score.
DEFAULT_DENSITY_K30Neighbours used for the density score.
NO_EVENT_LABELSlocal:no_biophony, local:other_biophonyLabels meaning "no target species here". They train as negative examples, never as a class of their own.

The classifiers are in active_learning/model_zoo/ and the scores in active_learning/samplers.py.

Change the phases

Each phase is one entry in the frontend's src/studyPhases/phases.ts. An entry switches parts of the Hub on or off: the projection (visualization.mode), clicking points (allowPointClick), the sidebar sections (sidebar.sampleProperties, sidebar.modelScores), and sorting (sort.nonModel, sort.model). The introduction and guide cards shown for each phase are in src/studyFlow/phaseContent.ts.

Which phases a deployment offers, and whether one is locked, is set with VITE_STUDY_* variables, without code changes; see Environment Setup.

Add an embedding model

YAPAT ships with BirdNET 2.4. Adding another model takes three steps:

  1. Implement the embedder next to app/services/birdnet_model.py.
  2. Call it from app/tasks/embedding_tasks.py. The tasks currently call BirdNET directly, whichever model the job names, so add a choice based on the job's model.
  3. Register the model with an Alembic migration that inserts a row into the embedding models table, with its window size, step size, and overlap.
Vector size. Embedding vectors are stored in a pgvector column of 1024 dimensions (app/models/embedding.py). A model with a different output size needs a projection to 1024 or a schema change.

Add an API endpoint

  1. Add a route to the matching router in app/api/, or create a new router and register it in app/main.py under /api.
  2. Put the logic in app/services/ and the request and response models in app/schemas/.
  3. For slow work, add a Celery task in app/tasks/ and return a task ID instead of waiting.
  4. Call the endpoint from the frontend in src/services/api.ts.

Access rules are in app/core/permissions.py; reuse them rather than checking roles by hand.

Change the quick-label species names

The scientific names shown for the species codes on quick-label buttons, for example SCIALT for Scinax alter, are listed in the frontend's src/constants/speciesLabels.ts.
