First Workflow

This page takes you from a fresh YAPAT installation to your first exported labels. Each step links to the guide with the details.

You need: YAPAT running (see Installation) and a folder of audio files on its data volume.

1. Sign in

Register on the sign-up page, or open an invitation link from your administrator, then sign in with your username and password. The Dashboard greets you with your role and the number of datasets you can access. Start Annotating opens the Annotation Hub, and a card opens each area you can use: Dataset Management, Annotate, Label Management, and, depending on your role, Team Management, Weakly Supervised Sound Event Detection (WSSED), and Study Logs. The Feed History card lists older feeds and is not needed for annotation; the Documentation card opens a manual built into the app.

2. Add a dataset

An administrator clicks Add Dataset on the Datasets page and picks the folder with the audio. YAPAT scans it in the background. Datasets →

3. Generate embeddings

On the dataset card, the administrator clicks Generate Embeddings. YAPAT cuts the audio into 3-second clips and prepares them for the model. Embeddings →

4. Build a label space

Optional, but recommended. In Label Management, describe what you want to label and freeze the list. Label Management →

5. Start annotating

Open the Annotation Hub, choose the dataset, click Generate Feed at the top right of the feed, and choose bootstrap mode. Listen to each clip and choose its labels. Annotation Hub →

6. Let the model learn

Keep labelling. After every 10 labels the model retrains on its own, and the feed shows the clips it is now least sure about. Active Learning →

7. Export

Open the Export menu on the dataset card and choose Export as CSV or Export as JSON. Import & Export →
