First Workflow

This walkthrough follows one dataset from registration to exported annotations. It assumes a running backend and frontend, as described in Installation.

1. Create an account and sign in

Accounts can be created on the sign-up page. Invitation links attach a new account to a team or to datasets:

  • A team invitation adds the new user to that team with the role stored in the link, either owner or user. Links created through the interface expire after two days by default.
  • A dataset invitation, created by an administrator, makes the new user a team owner of the team that holds the invited datasets. For datasets without a team, it grants direct access instead.

2. Register a dataset

In the web interface, administrators add datasets from the Datasets page. Adding a dataset means choosing a folder on the mounted data volume and a dataset type, PAM or FOCAL_RECORDINGS. A background task then scans the folder and records each audio file it finds.

3. Generate embeddings

Embeddings are vectors computed for short audio segments. Similarity search and active learning depend on them. On the dataset card, an administrator or team owner chooses an embedding model and starts the job. It runs on a Celery worker and, when finished, leaves the dataset with a snippet set that feeds can use.

4. Build a feed

Once the dataset is ready for feeds, open the Annotation Hub and choose a mode:

  • Random — an unordered sample, useful for a first look.
  • Similarity — snippets close to a reference sound.
  • Active Learning — snippets ranked by a model.
  • Filter — snippets narrowed by annotation status, location, or species.
  • Validate — unannotated snippets ordered by model confidence.

5. Annotate

Review each snippet's spectrogram and audio, and assign labels from the active label space. In the model-assisted modes each card offers Accept, Reject, and Modify actions for the model's suggestion; in the other modes you pick labels directly. Confirmed labels are saved to the backend database.

6. Revisit earlier feeds

Feeds from the random, similarity, and filter methods are saved per user. The Feed History page lists the most recent ones so you can reopen a batch instead of rebuilding it.

7. Export

A dataset's annotations can be exported as JSON or CSV. See Import & Export for the filters and the columns.

Going further. Once labels exist, an active-learning session can train a model on them and rank the remaining snippets. See Active Learning.
