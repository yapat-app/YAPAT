First Workflow

This page takes you from a fresh YAPAT installation to your first exported labels. Each step links to the guide with the details.

You need: YAPAT running (see Installation) and a folder of audio files on its data volume.

1. Sign in

YAPAT has no public sign-up button. Open the YAPAT address and click Sign in on the home page, then enter the username and password of the account an administrator created for you. If you were invited to a team, open the invitation link instead: it shows the login form with your role filled in, and the button reads Register. Choose a username and password, register, then sign in. See Teams.

After signing in you land on the Dashboard. It greets you with your role and the number of datasets you can access. Start Annotating opens the Annotation Hub, and a card opens each area you can use: Dataset Management, Annotate, Label Management, and, depending on your role, Team Management, Weakly Supervised Sound Event Detection (WSSED), and Study Logs. The Documentation card opens this documentation.

2. Add a dataset

An administrator clicks Add Dataset on the Datasets page and picks the folder with the audio. YAPAT scans it in the background. Datasets →

3. Generate embeddings

On the dataset card, the administrator clicks Generate Embeddings. YAPAT cuts the audio into 3-second snippets and prepares them for the model. Embeddings →

4. Build a label space

Optional, but recommended. In Label Management, describe what you want to label and submit the list; a team owner then makes it active. The short list of labels annotators click is managed separately, as quick labels on the dataset card. Label Management →

5. Build your model

YAPAT ranks snippets with a classifier trained on the dataset's embeddings. A new dataset has no classifier yet. When an administrator or team owner opens it in step 6, they enter a model family name and choose how the first model is trained:

StartFirst modelSuitable when
BootstrapTrained from your labels on randomly chosen snippets.No labelled data is available. This is the default.
Cold startTrained immediately from existing ground-truth labels, given as a metadata file and a label config file. Administrators and team owners only.Part of the dataset is already labelled.
WSSED modelA model trained with WSSED is registered as the first model.Recordings are labelled by species, but not by time.

An administrator can also link a reference pool to the dataset or its team: labelled datasets whose labels are added to every training run. Each run saves a new checkpoint (v0, v1, …) in the model family, and the active checkpoint ranks the feed. How the model is built →

6. Start annotating

Open the Annotation Hub and choose the dataset. If it has no model yet, an administrator or team owner clicks Generate Feed at the top right of the feed and enters the model family name and the start chosen in step 5. Once the dataset has a model, the feed loads on its own for everyone. Then listen to each snippet and choose its labels. How the feed works → Annotation Hub →

7. Let the model learn

Keep labelling. After every 10 labels the model retrains, saves a new checkpoint, and the feed shows the snippets it is now least sure about. Active Learning →

8. Export

Open the Export menu on the dataset card and choose Export as CSV or Export as JSON. Import & Export →
