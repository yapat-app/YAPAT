Installation

YAPAT runs as a backend (in Docker) and a web frontend. This page sets up both on your machine in three steps.

Prerequisites

RequirementWhy
Docker with Docker ComposeRuns the backend, database, and workers.
Node.js 20.19 or newerRuns the frontend.
NVIDIA graphics processing unit (GPU), optionalSpeeds up embeddings and model training.

1. Get the code

git clone --recurse-submodules https://github.com/yapat-app/YAPAT.git
cd YAPAT
git -C backend checkout finalUserStudy
git -C frontend checkout finalUserStudy

The backend and frontend are Git submodules; the two checkout commands select their release branch.

2. Start the backend

cd backend
cp .env.example .env
# In .env, set HOST_DATA_ROOT to the folder that holds your audio
docker compose up

The first start builds the images and runs the database migrations. When it is up, the application programming interface (API) answers at http://localhost:8000, with interactive API docs at http://localhost:8000/docs.

3. Start the frontend

cd frontend
npm install
cp .env.example .env
npm run dev

Open http://localhost:3000 and create your account. Next, follow First Workflow.

Phases. The example frontend settings lock the Annotation Hub to phase 1 and turn on guided instructions. To use all five phases, change the VITE_STUDY_* values in frontend/.env; see Environment Setup.

Optional services

ServiceNeeded forSetting
Ontology service (oe_yapat)The label-space chat in Label ManagementOE_YAPAT_SERVICE_URL (default http://localhost:8002)
Weakly Supervised Sound Event Detection (WSSED) serverTraining sound event detection models from labelled recordings (FOCAL_RECORDINGS datasets), used as a first active-learning modelWSSED_GPU_SERVER_URL (default http://localhost:8003)

Everything else works without them. When the backend runs in Docker and a service runs on the same host, use http://host.docker.internal:<port>. Ask the project maintainers how the ontology service's HTTP endpoint is deployed; the oe_yapat repository contains the tool server but not that endpoint.

For developers.
  • The backend stack starts PostgreSQL (5432), Redis (6380), the API (8000), two Celery workers, Celery beat, and Flower (5555). See Docker.
  • docker compose up -d runs in the background; docker compose down -v also deletes the data volumes.
  • All settings: Environment Setup.
