What is YAPAT?

YAPAT (Yet Another PAM Annotation Tool) is an AI-powered annotation tool for audio from passive acoustic monitoring (PAM): recorders left in the field that capture sound for days or months.

Listening through all of that audio takes experts far too long. YAPAT uses a model to pick the short clips most worth an expert's attention, and learns from every label the expert gives. You spend your time where it improves the data most.

How it works

  1. Add your recordings. Point YAPAT at a folder of audio. It cuts the recordings into 3-second clips and computes embeddings for them.
  2. Decide what to label. Build your team's label space: describe the sounds in plain language and keep the matching species and concepts.
  3. Label. The Annotation Hub shows you the clips the model is least sure about. You listen, look at the spectrogram, and choose labels.
  4. The model learns. After every 10 labels it retrains and picks the next clips. Repeat.
  5. Export. Download your labels as comma-separated values (CSV) or JavaScript Object Notation (JSON).
You stay in charge. The model decides the order of the clips, never the answer. Its guesses are not shown, and every stored label is one a person chose.

Main features

FeatureWhat it gives you
Active learningA feed of the most useful clips, re-ranked as you label.
Label spacesLabels linked to trusted sources such as the Global Biodiversity Information Facility (GBIF), built in a chat.
Projection and filtersA map of all clips, and filters by location, date, time, and model scores.
PhasesIntroduce the tools step by step, with optional guided instructions and interaction logs.
TeamsShare datasets and label spaces, with administrator, owner, and annotator roles.
Sound event detection (WSSED)Weakly Supervised Sound Event Detection (WSSED): a way to train a sound event detection model from recordings that are labelled only with the species they contain, not with the exact time of each call. An optional training server builds such a model, and active learning can start from it instead of from random clips.

Architecture

Two services are optional. The ontology service (oe_yapat) looks up species and environmental terms for the label-space chat. The WSSED server runs on a machine with a graphics processing unit (GPU) and trains a sound event detection model from labelled recordings, which YAPAT can then use as its first active-learning model; see WSSED. Everything else works without them.

For developers. Every feature is available through the REST API (the HTTP interface the web app itself uses) under /api; long-running work runs on Celery background workers. Start with Architecture and the REST API reference.
