Annotation Hub

The Annotation Hub is where annotation happens. One workspace handles every sampling mode; the mode is selected with a URL parameter and the dataset with another.

Opening a mode

/annotate?mode=al&dataset_id=1
/annotate?mode=validate&dataset_id=1

Supported modes are al (active learning), validate, similarity, and filter. When no mode is given, the hub opens a random feed. If no dataset is specified, the hub restores the dataset you last annotated with, which the browser remembers per user.

The workspace

The classic workspace is a resizable split view:

  • ProjectionView — a spatial view of the snippets, useful for seeing clusters and where the current snippet sits.
  • PredictionFeed — the stack of snippet cards to review, each with its spectrogram, player, and labels.

In active-learning mode, the projection can be coloured by model prediction, by uncertainty, or by taxon. The projection is shown in two dimensions.

Configuring a feed

Each mode opens its own configuration dialog:

Mode Options
Random Feed limit.
Similarity Upload a reference audio clip, choose its start and end seconds, and set the limit.
Filter Annotation status, locations, species, and limit.
Active learning / Validate Model checkpoint (or a cold-start configuration), top-K, and label scope. Validate adds a minimum-confidence threshold.

In a cold-start active-learning configuration, the expert supplies the model family name, an embedding model, and optionally a ground-truth metadata file and a label-config file, and may run training before inference.

Reviewing and labelling

For model-assisted modes, each card presents an Accept / Reject / Modify prompt. Accept confirms the suggestion, Reject marks it wrong, and Modify lets you edit the labels before confirming. In the classic modes, labels are chosen directly from the active label space.

Confirmed labels are saved to the backend. In active-learning mode the same action also records feedback, which counts toward the auto-retrain threshold.

Remember. Feeds are snapshotted. Feed History lets you reopen a previous configuration instead of rebuilding it.
