Annotation Hub

The Annotation Hub is where you label audio. YAPAT shows you the snippets its model is least sure about, you choose the labels, and the model learns from every answer you give.

You need: a dataset with embeddings. See Datasets.

Steps

  1. Open Start Annotating on the Dashboard, or Active Learning on a dataset card.
  2. Choose the dataset in the toolbar. If it has a model, the feed loads on its own; otherwise an administrator or team owner starts it with Generate Feed at the top right of the feed (see The feed).
  3. On each snippet, look at the spectrogram, play the audio, and choose one or more labels.
  4. Move on to the next snippet. Your labels are saved automatically.

The three areas

AreaWhat it does
FiltersNarrow the feed and the projection by label status, location, date, time of day, and model scores. See Filters and Model Scores.
Feature ProjectionA map of all snippets in the dataset, where similar sounds sit close together. Clicking a point opens that snippet. See The projection.
FeedThe snippets to label, one at a time, with sort options above them.

The feed

The feed is the ordered list of snippets the Hub shows you to label. How it starts depends on whether the dataset already has a model.

A dataset with a model

When the dataset has an active model checkpoint, for example from earlier training or a registered WSSED model, the Hub ranks its snippets and loads the feed on its own, least certain first, with the first snippet open. There is nothing to click.

A dataset without a model

The first time a dataset is used there is no model yet. Administrators and team owners then see a Generate Feed button at the top right of the feed; annotators see the feed once the dataset has a model. The button opens a dialog that asks for a Model family name and how to start. The Do you have ground-truth metadata? switch chooses:

  • Off: bootstrap mode — start with randomly chosen snippets. The first model is trained from your labels. This is the usual choice. Top-K (1 to 500) sets how many snippets the feed shows; with Return only Top-K suggestions switched off, it returns all of them.
  • On: cold start — train a first model from existing ground-truth labels. The dialog then asks for the embedding model, the metadata path, the label config path, and the device (CPU or CUDA), and can run inference automatically once training finishes.

Click Apply to start. Once the dataset has a model, the button disappears and the feed loads on its own from then on. See How the model is built.

Dialog says "No READY default snippet set found"? The dataset has no embeddings yet. Generate them on the dataset card first; see Troubleshooting.

What happens next: label the open snippet as described below. After every 10 labels the model retrains in the background and the feed refreshes with a new ranking.

Labelling a snippet

Choose labels from the quick-label list (managed on the Datasets page), or search the Global Biodiversity Information Facility (GBIF) for a species that is not in the list; a species you pick from the search is added to your own quick labels. A snippet can have several labels.

The model's own guess is never shown on the snippet. This keeps your answer independent, so every stored label is one a person chose. See Active Learning.

  • Press ↑ and ↓, or the arrows next to the snippet name, to move to the previous or next snippet.
  • Remove one label with its ×, or all of a snippet's labels with Clear all.
  • A labelled snippet shows a Labeled badge next to its file name.
  • Use No biophony when you hear no animal sound at all. YAPAT treats it as "none of the target species", so the model learns from it without turning it into a species.

The model retrains on its own

After every 10 labels, YAPAT retrains the model in the background and refreshes the feed with the new ranking. There is nothing to click.

The projection

The projection shows every snippet of the dataset as a point; snippets that sound alike sit close together. Coloured points are labelled snippets, and the legend shows which colour belongs to which label. The buttons above it switch between three standard methods for drawing the snippets on a flat map: t-distributed stochastic neighbor embedding (t-SNE), Uniform Manifold Approximation and Projection (UMAP), and principal component analysis (PCA). Zoom with the + and − buttons, and double-click to reset the zoom. The ring marks the snippet open in the feed, and clicking any point opens that snippet. The counter above the legend shows how many snippets the current filters leave visible and how many of them are labelled.

Study logs

YAPAT can record interactions such as label choices, playback, and filter changes. Administrators review them under Study Logs on the Dashboard: first a list of participants, then each participant's sessions, then the timeline of events in a session, which can be downloaded as comma-separated values (CSV). Logging is off by default; an administrator switches it on.

For developers.
  • The Hub lives at /annotate?dataset_id=<id>.
  • Interaction logging is switched on with VITE_STUDY_LOGGING_ENABLED. See Environment Setup.
  • The retrain threshold is RETRAIN_AFTER in the backend's active_learning/config.yaml.
  • Endpoints: Active Learning API.
