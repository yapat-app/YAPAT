Label Management

The label-management workspace builds a label space through a guided conversation. It is opened from the Taxonomies page (route /pre-annotation), where a team and an optional dataset scope are selected first.

The workspace

Two panels work together:

  • Taxonomy chatbot — you describe the concepts you need in natural language; the assistant retrieves candidate matches from reference resources and discusses them.
  • Label space — the growing list of confirmed concepts, with the source information attached to each.

A session, step by step

  1. Start a conversation. A session is created for the selected team and dataset. It can be seeded from the team's current active label space (seed_from_active).
  2. Elicit concepts. Each message is sent to the taxonomy assistant, which proposes grounded concepts. Candidates can be inspected and added to the label space, either in bulk or individually.
  3. Refine. Items can be removed from the label space while it is still editable; concepts that do not fit an external resource are kept as local representations.
  4. Submit. Submitting turns the session's concept list into a custom taxonomy stored as a numbered version in submitted status for the team owner to review.

A conversation can also be cancelled without producing a taxonomy.

Reviewing and activating versions

Team owners (and administrators) see the submitted versions for their team and can promote one to be the team's active label space; the previously active version returns to submitted. Only one version is active at a time; the active version is the one a new session can be seeded from. Removing a custom taxonomy through the API archives it rather than deleting it.

Where grounding comes from

Species concepts are matched against GBIF, environmental concepts against ENVO through OLS, and unmatched concepts fall back to Wikipedia or a local ontology representation. The details are covered under Grounding.

Dependency. The chatbot requires the ontology service (oe_yapat) to be running. See Installation.
