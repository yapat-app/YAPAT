Label Management

The label-management workspace builds a label space through a guided conversation. It is opened from the Label Management card on the Dashboard (route /pre-annotation). When you belong to more than one team, or are an administrator, you first choose the target team that will own the frozen label space.

The workspace

Two panels work together:

  • Taxonomy chatbot — you describe the concepts you need in natural language; the assistant retrieves candidate matches from reference resources and discusses them.
  • Label space — the growing list of confirmed concepts, with the source information attached to each.

A session, step by step

  1. Start a conversation. A session is created for the selected team, or for your first team when no team is chosen.
  2. Elicit concepts. Each message is sent to the taxonomy assistant, which proposes grounded concepts. Candidates can be inspected and added to the label space, either in bulk or individually.
  3. Refine. Items can be removed from the label space while it is still editable, and further messages refine the search.
  4. Freeze. The Add To label space list button freezes the session's concept list into a custom taxonomy with status active, named Label space followed by the date and time. The button then changes to Label Space created, Start Annotating?, which opens the Annotation Hub.

After freezing

A frozen conversation cannot be edited. The Annotation Hub adds the concepts of the team's most recently frozen label space to the list of labels annotators can choose from. There is no review or promotion step; freezing another label space creates a further taxonomy.

Where grounding comes from

The ontology service looks up species in GBIF and environmental concepts in ENVO through OLS, and can also return Wikipedia entries or build a local ontology module for a concept without a match. The details are covered under Grounding.

Dependency. The chatbot requires the ontology service (oe_yapat) to be running. See Installation.
