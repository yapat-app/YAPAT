Feed History

Feed History is not part of the user-study workflow. The page is still reachable from the Dashboard, but the Annotation Hub does not open the entries it lists: every feed in the Hub comes from active learning.

What the page shows

The page lists feed snapshots stored by the backend's older, non-active learning feed endpoint. In the user-study interface such snapshots are created only by the older Generate Feed button on a dataset card. Each entry shows the method, the number of snippets, and the creation time.

Opening an entry

The View Feed button opens the Annotation Hub with the entry's feed_id. The user-study Hub ignores that parameter and shows the active-learning feed of the selected dataset, not the snippets of the snapshot.

Instead. To continue annotating a dataset, open it in the Annotation Hub; the Hub restores the dataset you last used.
